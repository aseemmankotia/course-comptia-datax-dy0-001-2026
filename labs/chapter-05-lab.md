# Chapter 5 Lab: Unsupervised Learning: Clustering and Dimensionality Reduction

**Estimated time:** 30 minutes

## Exercise

Apply PCA and t-SNE for visualization, then run k-means and DBSCAN on the same dataset, comparing cluster quality using silhouette score

## Key takeaway

Choose clustering and dimensionality reduction techniques based on the true geometric structure of the data, not convenience or default settings.
