# Chapter 12 Lab: Recommender Systems, Anomaly Detection, and Other Applied Techniques

**Estimated time:** 35 minutes

## Exercise

Build a collaborative filtering recommender using matrix factorization (SVD) and an isolation-forest anomaly detector on transaction data, evaluating with precision@k and AUC

## Key takeaway

Recommender systems and anomaly detection each require specialized evaluation metrics and hybrid strategies that account for sparse data and extreme class imbalance.
