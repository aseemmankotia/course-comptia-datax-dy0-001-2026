# Chapter 11 Lab: Optimization Methods, NLP, and Computer Vision Applications

**Estimated time:** 35 minutes

## Exercise

Fine-tune a pretrained transformer for text classification and a pretrained CNN for image classification via transfer learning, comparing SGD vs Adam optimizer convergence on the same task

## Key takeaway

Specialized applications require matching the optimizer, architecture, and transfer learning strategy to the data size and problem structure, not defaulting to the most powerful option.
