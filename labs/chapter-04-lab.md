# Chapter 4 Lab: Supervised Learning: Regression, Trees, and Ensembles

**Estimated time:** 35 minutes

## Exercise

Train and tune a gradient boosting classifier and a random forest on the same dataset in scikit-learn, then compare bias-variance behavior using learning curves

## Key takeaway

Match the ensemble strategy to the error you need to reduce: bagging for variance, boosting for bias, and choose SVM kernels based on the data's separability.
