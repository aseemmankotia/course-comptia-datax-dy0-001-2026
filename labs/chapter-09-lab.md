# Chapter 9 Lab: Probability Distributions and Hypothesis Testing

**Estimated time:** 30 minutes

## Exercise

Run a t-test, a chi-squared test, and a one-way ANOVA in Python using scipy.stats on a sample dataset, then correctly interpret the resulting p-values and confidence intervals

## Key takeaway

Match the hypothesis test to the data type and number of groups, and always interpret p-values relative to the null hypothesis, not as a probability of truth.
