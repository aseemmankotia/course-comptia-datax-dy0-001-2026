# Chapter 6 Lab: Deep Learning Architectures, Regularization, and Bias-Variance Tradeoff

**Estimated time:** 40 minutes

## Exercise

Build a small CNN for image classification and a Transformer-based text classifier, compare both to a classical baseline, then run a Bayesian hyperparameter search with Optuna

## Key takeaway

Diagnose bias vs variance with learning curves first, then pick the architecture and regularization technique that addresses the actual diagnosed problem.
