# Chapter 8 Lab: MLOps: Experiment Tracking, Deployment, and Drift Monitoring

**Estimated time:** 35 minutes

## Exercise

Track experiments with MLflow, register a model version, simulate a canary deployment, and set up a drift-detection check comparing training vs production feature distributions

## Key takeaway

Robust MLOps requires monitoring both data and concept drift, with a rollback-capable deployment pattern for every production model.
