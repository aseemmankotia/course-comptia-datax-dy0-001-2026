# Chapter 2 Lab: Feature Engineering and Selection Strategies

**Estimated time:** 30 minutes

## Exercise

Build a feature selection pipeline in scikit-learn comparing mutual information (filter), recursive feature elimination (wrapper), and Lasso coefficients (embedded) on the same tabular dataset

## Key takeaway

Match the feature selection method to the compute budget and interaction complexity — filter for speed, wrapper for accuracy, embedded for a practical middle ground.
