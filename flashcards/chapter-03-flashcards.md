## Chapter 3: Model Evaluation, Iteration, and Communicating Outcomes — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | ROC-AUC vs PR-AUC — when does PR-AUC become the better metric? | When the positive class is rare/imbalanced (e.g., <10% prevalence). ROC-AUC is inflated by the large negative class's true negative rate. Exam tip: fraud, churn, and disease-detection scenarios with heavy imbalance almost always point to PR-AUC. |
| 2 | Precision formula | Precision = TP / (TP + FP). Answers: 'Of all predicted positives, how many were correct?' Exam tip: high precision = low false positive rate. |
| 3 | Recall formula | Recall = TP / (TP + FN). Answers: 'Of all actual positives, how many did we catch?' Exam tip: prioritize recall when missing a positive is costly (fraud, disease). |
| 4 | F1 score formula | F1 = 2 × (Precision × Recall) / (Precision + Recall). Harmonic mean — punishes extreme imbalance between precision and recall more than a simple average. |
| 5 | Time-series split vs standard k-fold | Time-series split (walk-forward validation) trains only on past data, validates on future folds sequentially. Standard k-fold shuffles data randomly. Exam tip: any temporally ordered dataset (sales forecasting, sensor data) requires time-series split to avoid leakage. |
| 6 | Stratified k-fold — when required? | Used when class distribution is imbalanced, to preserve the same class ratio in every fold. Exam tip: without stratification, minority-class folds can have too few samples for stable precision/recall estimates. |
| 7 | Calibration curve — what does the diagonal line represent? | Perfect calibration: predicted probability equals observed frequency. Points above the diagonal = model is under-confident; points below = over-confident. Exam tip: calibration is separate from discrimination (AUC) — a model can have high AUC but poor calibration. |
| 8 | Platt scaling vs isotonic regression | Platt scaling fits a logistic curve to recalibrate probabilities (good for small datasets, monotonic assumption). Isotonic regression is a non-parametric, more flexible fit but requires more data and can overfit with small samples. Exam tip: choose isotonic for large calibration sets, Platt for small ones. |
| 9 | Confusion matrix quadrants | TP = correctly predicted positive; FP = predicted positive, actually negative (Type I error); FN = predicted negative, actually positive (Type II error); TN = correctly predicted negative. Exam tip: FP drives precision down, FN drives recall down. |
| 10 | Iterative model refinement loop — standard order | 1) Baseline model → 2) Error analysis on confusion matrix/misclassified cases → 3) Feature/data adjustment → 4) Retrain → 5) Re-validate with same CV strategy → 6) Compare against baseline metric. Exam tip: never change the evaluation strategy mid-loop — it breaks apples-to-apples comparison. |
| 11 | A/B testing a model in production — key requirement | Random assignment to control/treatment groups, a single predefined business metric, and a statistical significance test (e.g., t-test, chi-square) run for a pre-calculated sample size/duration before concluding. Exam tip: never judge results by peeking early — it inflates false positive rate. |
| 12 | Statistical significance vs business significance | Statistical significance = effect is unlikely due to chance (p-value/CI). Business significance = effect size is large enough to justify cost/action. Exam tip: large sample sizes can make tiny, meaningless effects 'statistically significant' — always check effect size and cost/benefit. |
