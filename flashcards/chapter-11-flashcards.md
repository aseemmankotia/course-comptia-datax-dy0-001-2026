## Chapter 11: Optimization Methods, NLP, and Computer Vision Applications — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Adam optimizer default hyperparameters? | beta1=0.9 (momentum), beta2=0.999 (RMS term), epsilon=1e-8. Exam tip: Adam adapts learning rate per parameter using both moments — faster convergence than plain SGD on non-convex deep nets. |
| 2 | SGD vs Adam — when does the exam favor SGD(+momentum)? | SGD with momentum often generalizes better on large-scale image tasks (e.g., ResNet training) and is preferred when compute time isn't constrained. Adam converges faster but can generalize worse. Exam tip: 'faster convergence, adaptive rates' → Adam; 'better generalization, simpler, well-tuned schedule' → SGD+momentum. |
| 3 | What does momentum add to gradient descent? | An exponentially weighted moving average of past gradients, smoothing updates and accelerating convergence in consistent gradient directions while damping oscillation. |
| 4 | Convex vs non-convex optimization — key difference? | Convex: single global minimum, any local min = global min (e.g., linear/logistic regression). Non-convex: multiple local minima/saddle points, common in deep neural networks. Exam tip: convexity guarantees convergence to global optimum; non-convex does not. |
| 5 | NLP pipeline order (high level)? | Tokenization → Embedding lookup → (Positional encoding) → Model (e.g., Transformer) → Task-specific output layer. Exam tip: tokenization comes first and handles OOV words via subword units (BPE/WordPiece). |
| 6 | What is a word/token embedding? | A dense vector representation of a token capturing semantic meaning, learned so similar words have similar vectors (e.g., word2vec, GloVe = static; BERT = contextual). Exam tip: contextual embeddings vary by sentence context, static embeddings do not. |
| 7 | Self-attention mechanism purpose in transformers? | Lets each token compute a weighted relevance score against every other token in the sequence, capturing long-range dependencies in parallel (no sequential recurrence needed). Exam tip: this replaced RNN/LSTM sequential processing. |
| 8 | Transfer learning for CV — typical workflow? | Take a model pretrained on a large dataset (e.g., ImageNet), freeze early convolutional layers (generic features: edges/textures), fine-tune later layers on the small target dataset. Exam tip: use this when target dataset is small. |
| 9 | Convolution operation — what does it extract? | Local spatial features (edges, textures, shapes) by sliding learned filters/kernels across the input; deeper layers combine these into higher-level features. |
| 10 | Object detection vs image classification — key output difference? | Classification: single label per image. Object detection: multiple labels AND bounding box coordinates for each detected object (e.g., YOLO, Faster R-CNN). Exam tip: 'locate objects in image' → detection, not classification. |
| 11 | What problem does gradient descent 'oscillation' with a high fixed learning rate indicate, and the standard fix? | Indicates learning rate too large relative to loss curvature; standard fix is adding momentum or lowering the learning rate (or using an adaptive optimizer like Adam). |
| 12 | Choosing NLP vs CV architecture — exam heuristic? | Sequential/text data with long-range dependencies → Transformer-based NLP models. Grid-structured spatial data (images) → CNN-based architectures, often with transfer learning if data is limited. Exam tip: match architecture to data structure, not just task popularity. |
