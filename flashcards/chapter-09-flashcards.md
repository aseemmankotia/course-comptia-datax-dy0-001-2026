## Chapter 9: Probability Distributions and Hypothesis Testing — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What does a p-value represent in hypothesis testing? | Probability of observing data as extreme or more extreme than what was seen, assuming the null hypothesis is TRUE. Exam tip: p-value is NOT the probability the null (or alternative) is true. |
| 2 | Standard significance level (alpha) used by default in most exam scenarios? | 0.05 (5%). Exam tip: reject null if p-value < alpha; this is the standard threshold unless the scenario states otherwise. |
| 3 | Type I error vs Type II error — define both. | Type I (alpha): rejecting a TRUE null hypothesis (false positive). Type II (beta): failing to reject a FALSE null hypothesis (false negative). Exam tip: lowering alpha reduces Type I error but increases Type II error risk. |
| 4 | t-test vs chi-squared vs ANOVA — when to use each? | t-test: compare means of 1-2 groups (continuous data). Chi-squared: test association between categorical variables. ANOVA: compare means across 3+ independent groups. Exam tip: ANOVA avoids inflated Type I error vs running multiple t-tests. |
| 5 | Paired t-test vs independent (two-sample) t-test? | Paired t-test: same subjects measured twice (before/after). Independent t-test: two separate, unrelated groups. Exam tip: matched/repeated measurements always signal 'paired'. |
| 6 | Central Limit Theorem (CLT) — core statement? | Sampling distribution of the sample mean approaches normal as sample size increases, regardless of population shape. Rule of thumb: n≥30 is 'large enough' on the exam. |
| 7 | Bonferroni correction formula for multiple comparisons? | Adjusted alpha = original alpha / number of tests (e.g., 0.05/20 = 0.0025). Exam tip: controls family-wise error rate but can be overly conservative with many tests. |
| 8 | Normal vs Binomial vs Poisson vs Exponential distribution — core use case for each? | Normal: continuous, symmetric data. Binomial: fixed number of trials, success/failure outcomes. Poisson: count of independent events per fixed interval. Exponential: time between events. Exam tip: 'events per hour' = Poisson; 'time until next event' = Exponential. |
| 9 | Confidence interval (CI) — what does a 95% CI mean? | If we repeated the sampling process many times, 95% of the constructed intervals would contain the true population parameter. Exam tip: it is NOT '95% probability the true value is in this specific interval'. |
| 10 | Hypothesis testing framework — standard steps in order? | 1) State null (H0) and alternative (H1) hypotheses. 2) Choose alpha. 3) Compute test statistic and p-value. 4) Compare p-value to alpha. 5) Reject or fail to reject H0. Exam tip: you never 'accept' H0, only 'fail to reject' it. |
| 11 | Statistical power — what does it represent and how is it related to Type II error? | Power = 1 - beta (probability of correctly rejecting a false null). Exam tip: increasing sample size increases power and reduces Type II error risk. |
| 12 | Why is a correction (e.g., Bonferroni) needed when running multiple hypothesis tests? | Running many tests at alpha=0.05 each inflates the overall family-wise error rate (chance of at least one false positive) well above 5%. Exam tip: 20 tests at alpha=0.05 uncorrected can yield ~64% chance of at least one false positive. |
