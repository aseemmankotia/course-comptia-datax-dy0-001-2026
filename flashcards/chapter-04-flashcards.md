## Chapter 4: Supervised Learning: Regression, Trees, and Ensembles — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Gini impurity formula vs Entropy formula for classification tree splits? | Gini = 1 − Σ(pᵢ²). Entropy = −Σ(pᵢ·log₂ pᵢ). Gini is faster (no log), entropy is more sensitive to class probability changes. Exam tip: both usually produce similar trees; Gini is the scikit-learn default. |
| 2 | L1 (Lasso) vs L2 (Ridge) penalty terms? | L1 adds λΣ\|wᵢ\| — drives coefficients to exactly zero (feature selection, sparse model). L2 adds λΣwᵢ² — shrinks coefficients toward zero but rarely to zero. Exam tip: 'sparse/feature selection' → L1; 'shrink all coefficients, keep all features' → L2. |
| 3 | Bagging's primary effect on bias-variance tradeoff? | Reduces VARIANCE by averaging many independent, high-variance parallel models (bootstrap samples). Bias stays roughly the same as a single base learner. Exam tip: Random Forest = bagging = variance reducer. |
| 4 | Boosting's primary effect on bias-variance tradeoff? | Reduces BIAS by sequentially fitting learners to correct prior errors/residuals. Can increase variance/overfitting if learning rate is too high or too many rounds are run. Exam tip: AdaBoost, Gradient Boosting, XGBoost, LightGBM = boosting = bias reducer. |
| 5 | Random Forest default max_features setting? | Classification default: sqrt(n_features). Regression default: n_features (all features, though 1/3 is a common manual choice). Exam tip: lower max_features increases tree diversity → reduces variance further. |
| 6 | Key XGBoost/LightGBM hyperparameters tested on exams? | learning_rate (eta), n_estimators, max_depth, subsample, colsample_bytree, reg_alpha (L1), reg_lambda (L2). Exam tip: lowering learning_rate + raising n_estimators trades training time for better generalization. |
| 7 | SVM RBF kernel gamma parameter — what does high gamma do? | High gamma = each training point has a small radius of influence → tighter, more complex decision boundary → higher risk of overfitting. Low gamma = smoother boundary, higher bias. Exam tip: gamma and C both control overfitting in RBF SVMs. |
| 8 | Four core assumptions of OLS linear regression? | 1) Linearity, 2) Independence of errors, 3) Homoscedasticity (constant residual variance), 4) Normality of residuals (not features). Exam tip: violating homoscedasticity → use weighted least squares or transform target. |
| 9 | Logistic regression cost function? | Log loss (binary cross-entropy): −[y·log(ŷ) + (1−y)·log(1−ŷ)], averaged over samples, optionally + regularization term. Exam tip: NOT mean squared error — MSE is non-convex for logistic regression's sigmoid output. |
| 10 | Stacking vs Blending — key difference? | Stacking: meta-model trained on out-of-fold (k-fold cross-validated) predictions of base models — uses full training set, less leakage. Blending: meta-model trained on predictions from a single held-out validation split — simpler, faster, slightly more prone to overfitting on that split. |
| 11 | SVM soft-margin C parameter — high C vs low C? | High C = less tolerance for misclassified points → narrower margin, lower bias, higher variance (overfitting risk). Low C = wider margin, more tolerance for violations → higher bias, lower variance. Exam tip: C is inversely related to regularization strength, same naming convention as logistic regression's C. |
| 12 | Typical gradient boosting learning_rate range and its tradeoff? | Typical range: 0.01–0.3. Lower learning_rate needs more n_estimators but generalizes better (less overfitting); higher learning_rate converges faster but risks overfitting. Exam tip: 'shrinkage' is another name for learning_rate. |
