## Chapter 12: Recommender Systems, Anomaly Detection, and Other Applied Techniques — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Precision@k formula for recommenders? | Precision@k = (relevant items in top k) / k. Exam tip: measures relevance density of the returned list, ignores items outside top k. |
| 2 | NDCG normalization — what does 'N' stand for and why does it matter? | Normalized. NDCG = DCG / IDCG, scaling score to [0,1] so rankings across users/queries with different numbers of relevant items are comparable. Exam tip: DCG alone isn't comparable across users. |
| 3 | New-user cold-start vs new-item cold-start — how is each typically solved? | New user: use content-based/popularity/demographic recommendations (no interaction history). New item: use content-based metadata matching since no user interactions exist yet. Exam tip: hybrid systems solve both. |
| 4 | Collaborative filtering vs content-based filtering — key data source? | Collaborative filtering: user-item interaction matrix (ratings/clicks). Content-based: item attribute/feature similarity to user profile. Exam tip: CF suffers cold-start, content-based doesn't (for existing item metadata). |
| 5 | What does matrix factorization (SVD-based) decompose the user-item matrix into? | Two lower-rank matrices of latent factors — one for users, one for items — whose dot product approximates the original ratings matrix. Exam tip: reduces dimensionality and sparsity issues. |
| 6 | ALS (Alternating Least Squares) — why is it preferred for large-scale implicit feedback? | It alternates fixing user factors/item factors and solving least squares for each, parallelizes well, and distributes across clusters (e.g., Spark MLlib). Exam tip: default answer for scalable implicit-feedback CF. |
| 7 | Isolation Forest — core mechanism for detecting anomalies? | Randomly partitions data recursively; anomalies require fewer splits to isolate (shorter path length) than normal points. Exam tip: no distributional assumption, scales well to high dimensions. |
| 8 | IsolationForest `contamination` parameter — default value? | 'auto' (scikit-learn). Sets expected proportion of outliers, which determines the anomaly score decision threshold. Exam tip: tune this if you know the approximate anomaly rate. |
| 9 | Autoencoder-based anomaly detection — how are anomalies flagged? | Train on normal data only; anomalies produce high reconstruction error since the model wasn't trained to reconstruct them well. Threshold typically set via a validation-set error percentile. Exam tip: useful for high-dimensional, nonlinear data. |
| 10 | Extreme class imbalance (e.g., 0.05% fraud) — why is accuracy a misleading metric? | A model predicting the majority class only can still score ~99.95% accuracy. Exam tip: use precision-recall AUC, recall-at-fixed-precision, or F1/F-beta instead. |
| 11 | Statistical threshold anomaly detection — two common univariate methods? | Z-score (flag \|z\| > 3 typically) and IQR method (flag values beyond Q1-1.5*IQR or Q3+1.5*IQR). Exam tip: both are univariate and break down in high-dimensional/multivariate data. |
| 12 | Hybrid recommender system — name three combination strategies (Burke's taxonomy) | Weighted (combine scores), Switching (choose method by context, e.g., cold-start vs mature user), and Feature combination (merge CF + content features into one model). Exam tip: switching hybrids commonly solve cold-start. |
