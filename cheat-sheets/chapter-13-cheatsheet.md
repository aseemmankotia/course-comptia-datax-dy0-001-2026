## Chapter 13 Cheat Sheet: Exam Pacing & Strategy

### Pacing Math
| Metric | Value |
|---|---|
| Target pace | ~1.8 min/question |
| Max questions | up to 90 |
| Approx total exam time | ~162 min (90 × 1.8) |
| PBQ time estimate | 3–4+ min each (varies) |

**Pace-check rule:** If you're noticeably behind pace by ~question 30, start flagging more and spending less time per question.

### Question-Type Time Strategy
| Type | Strategy |
|---|---|
| Multiple-choice | Steady pace, flag uncertain ones, don't over-analyze |
| PBQ | Triage by confidence — bank easy wins first, tackle hard ones with leftover time |
| Stats/math | Estimate order of magnitude, eliminate outlier answers — don't fully compute |

### Elimination Technique for Distractors
- Eliminate options that add **unstated conditions/scope** (extra services, extra steps) not in the scenario.
- Eliminate options that are **deprecated** or **don't fully meet all stated requirements**.
- Prefer the option matching scenario scope **exactly** — 'more thorough' ≠ 'correct'.

### Domain-Weighted Review Priority
1. Review flagged questions starting with the **heaviest-weighted domain**.
2. Descend to lighter domains as time allows.
3. Rationale: fixing errors in high-weight domains yields the largest score gain per minute spent.

### Final-Pass Checklist (do this in order)
| Step | Action |
|---|---|
| 1 | Confirm **zero blank answers** — guess if unsure (assuming no guessing penalty) |
| 2 | Revisit flagged questions, heaviest domain first |
| 3 | Verify all **PBQ configurations/inputs were saved**, not just attempted |
| 4 | Only change an answer if you find a **concrete reasoning error** — not gut feeling alone |
| 5 | Submit once all above are confirmed — don't over-spend remaining time re-reading settled questions |

### Key Reminders
- Never leave a question blank if there's no guessing penalty on this exam.
- Flagging ≠ scoring mechanism — it's a navigation tool only.
- PBQs have a higher effort-to-point ratio than multiple-choice — prioritize attempting all of them before extensive multiple-choice re-checks.
